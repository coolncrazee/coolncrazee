### MetaCogni™ — AI cost visibility & prompt intelligence
🌐 **[metacogni.ai](https://metacogni.ai)** · 🧩 **[Install on Chrome Web Store](https://chromewebstore.google.com/detail/metacogni-ai-cost-tracker/caeohgeaelmbkgdfpjdjefjdlfkhpdkl)** · 🎬 **[Demo video](https://youtu.be/BCtM8z3oBYc)**

A platform that shows people what their AI usage actually costs and helps them fix
prompts *before* an expensive model call runs.
- **Browser extension** (Chrome MV3) for **Claude, ChatGPT & Gemini** — live token
  usage, subscription-budget impact, "context tax," and prompt-improvement hints, in-page.
- **Multi-model web app** — pipeline routing across models, **cost prediction before
  send**, prompt optimization, and local agent telemetry.
- **On-device ML** — runs a quantized MiniLM-L6-v2 (ONNX) embedding model in the
  browser, so prompts never leave the machine; plus a trained model that forecasts when
  a user will hit their plan limits.
- **Stack:** JavaScript/TypeScript · Chrome MV3 · ONNX Runtime Web · Python · Vercel
- **My role:** sole founder — concept, full build (extension + web app + ML), and GTM.
